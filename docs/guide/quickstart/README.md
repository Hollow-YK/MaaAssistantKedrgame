## 对比

当然，您也可以根据下面的内容，自行选择合适的方案。

### 运行方式

| 运行方式 | 运行环境 | 优势 | 限制 |
| --- | --- | --- | --- |
| 电脑端+模拟器 | Windows 10 / 11 + 模拟器 | 功能完整，界面成熟，任务配置方便 | 需要安装模拟器 |
| 安卓端 | Android 10 及以上的设备 | 无需电脑 | 需要 Shizuku 或 root 权限 |
| 电脑端+真机 | Windows 10 / 11 + Android 设备 | 无需模拟器 | 需要 ADB ，风险高 |

### 界面

| 界面 | 平台 | 说明 |
| --- | --- | --- |
| **MXU** | 电脑端 | 配置简单、交互方便 |
| **MFAA** | 电脑端 | 内容分区展示，自由度高 |
| **MaaFwApp** | 安卓端 | Android 客户端 |
