# MaaFwApp（安卓）向导

这篇指南会教你如何在安卓设备上安装和使用 MAK 。

## 第一步：检查你的设备

在开始之前，请确认你的设备满足以下条件：

1. 你的设备系统是 **Android 10（API 29）或更高版本**
2. 你的设备已安装 **Shizuku**，或已获取 **root** 权限
3. 你的设备架构是 **arm64-v8a**（绝大多数手机）或 **x86_64**（部分模拟器）

::: info 什么是 Shizuku？
Shizuku 是一个让应用在无需 root 的情况下获得部分系统权限的工具。MAK 通过它完成截屏和模拟点击，
不需要连接电脑或 ADB。

如果你还没安装 Shizuku，请先前往 [Shizuku 官网](https://shizuku.rikka.app/) 下载安装。
:::

::: warning 注意
安卓端只提供后台虚拟屏模式，**Android 9 及以下版本无法运行**。
:::

---

## 第二步：下载 MAK

1. 打开浏览器
2. 在地址栏输入以下网址，然后按回车键：

   ``` text
   https://github.com/Hollow-YK/MaaAssistantKedrgame/releases
   ```

3. 你会看到一个下载页面，找到最新版本（排在最上面的那个）。MAK 提供的 **MaaFwApp** 安装包有以下几种：

   | 界面 | 文件类型 | 文件名示例 | 推荐程度 |
   | ------ | --------- | ----------- | --------- |
   | **MaaFwApp** | 通用包 | `MAK-android-universal-xxx.apk` | ⭐ 推荐 |
   | **MaaFwApp** | 单架构包 | `MAK-android-arm64-v8a-xxx.apk` | 推荐 |
   | **MaaFwApp** | 单架构包 | `MAK-android-x86_64-xxx.apk` | 按需 |

   通用包同时包含两种架构，体积较大；单架构包体积较小，但只能安装在对应架构的设备上。
   不确定设备架构时，选择通用包即可。

---

## 第三步：安装

1. 点击下载的 `.apk` 文件
2. 如果系统提示「禁止安装未知来源应用」，按提示允许当前浏览器或文件管理器安装应用
3. 安装完成后，打开「雪松小助手」

::: tip 提示
如果之前装过其他包名的 MAK（例如测试包），需要先卸载旧包再安装，否则可能提示签名冲突。
:::

---

## 第四步：授予权限

MAK 需要截屏和模拟点击权限，安卓上通过 Shizuku 或 root 授予，**不需要连接 ADB**。

::: tabs#android-permission

@tab Shizuku

1. 安装并启动 [Shizuku](https://shizuku.rikka.app/)
2. 按 Shizuku 的引导完成授权（Android 11 及以上可通过无线调试启动）
3. 打开 MAK，按提示允许 MAK 使用 Shizuku

@tab root

1. 确保设备已 root，并已授予 MAK root 权限
2. 打开 MAK，按提示完成授权

:::

---

## 第五步：初次使用 MAK

1. **启动 MAK**：在桌面找到「雪松小助手」图标，点击打开
2. **添加任务**：按照当前界面的提示添加或勾选你想要 MAK 帮你完成的任务
3. **选择设备**：在设备列表中选择当前设备
4. **开始运行**：点击界面中的开始按钮，MAK 就会开始工作了！

---

## 第六步：了解使用限制

- 客户端在后台虚拟屏上运行，任务执行期间可以息屏或切换到其他应用。
- 分辨率固定为 1280×720，不需要手动设置。
- 资源随 APK 绑定，**不支持热更新**；更换资源需要重新安装新包。
- 应用内更新检查依赖 Mirror 酱，本仓库暂未接入，请手动前往 Release 页面下载新版本。
