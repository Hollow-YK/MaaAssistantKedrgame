# MFAA 常见问题

本页收录 MFAA 界面相关的常见问题。通用问题见[常见问题总览](./)。

## 界面与配置

::: details 什么是 MFAA？

**MFAA**（MFAAvalonia）是基于 [Avalonia UI](https://github.com/AvaloniaUI/Avalonia) 构建的
[MaaFramework](https://github.com/MaaXYZ/MaaFramework) 通用 GUI，为本项目提供另一种开箱即用的
图形界面。

:::

::: details 为什么提供 MFAA？

MFAA 与 MXU 支持相同的任务，但界面布局与操作方式不同。MFAA 将任务列表、任务设置、实时视图与
日志分区展示，便于在同一页面查看配置与运行状态。

:::

::: details 什么是配置 / 标签页？

MFAA 在窗口顶部以标签页的形式展示配置，每个标签页相当于一套配置方案。每个配置中均可选择资源
类型、控制器类型与当前控制器，并管理该配置的任务列表。

:::

::: details 如何切换或新建配置？

- 直接点击顶部标签页即可切换；点击右侧 **+** 可新建配置。
- 也可进入左下角「设置」→「切换配置」：在「当前配置」中切换，或填写「新增配置名称」后点击
  「添加」，基于当前配置新建配置。

:::

::: details 关于定时执行配置

进入「设置」→「定时执行」可设置定时执行计划，并在「自定义配置选择」中指定需要执行的配置。

开启「强制定时启动」后，若定时触发时已有任务正在运行，MFAA 会先停止当前任务，待停止完成后
再启动新的任务。

:::

::: details MFAA 主界面包含哪些区域？

左侧提供以下主要入口：

- **主页**：管理当前配置的资源、控制器与任务。
- **总控台**：集中查看和管理运行内容。
- **截图**：使用截图相关功能。
- **设置**：修改配置、运行与界面等选项。

「主页」中的区域如下：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 资源与控制器 | 页面顶部 | 选择资源类型、控制器类型与当前控制器 |
| 任务列表 | 左侧 | 添加、启用任务并调整执行顺序 |
| 任务设置 | 中间上方 | 修改当前任务的选项 |
| 任务说明 | 中间下方 | 查看当前任务的说明 |
| 实时视图 | 右侧上方 | 查看设备截图 |
| 日志 | 右侧下方 | 查看连接、任务执行与错误信息 |

:::

::: details 设置中可以调整哪些内容？

- **切换配置**：切换已有配置，或基于当前配置新建配置。
- **定时执行**：设置配置的定时执行计划。
- **性能设置**：调整性能相关选项。
- **运行设置**：调整任务运行相关选项。
- **连接设置**：调整设备连接相关选项。
- **启动设置**：调整软件启动时的相关选项。
- **界面设置**：调整界面显示相关选项。
- **外部通知**：配置外部通知。
- **热键设置**：配置快捷键。
- **更新设置**：调整更新相关选项。
- **关于我们**：查看软件信息。

:::

::: details 什么是资源类型？

资源类型用于选择游戏的渠道版本：

- **官服**：从官网下载的游戏版本。
- **B 服**：在通用资源的基础上加载 Bilibili 渠道资源。
- **TapTap**：在通用资源的基础上加载 TapTap 渠道资源。

请根据实际安装的游戏版本，在配置页顶部选择对应的资源类型。

:::

## 任务与连接

::: details 什么是任务？

MAK 的各个自动化功能作为独立任务提供。在左侧任务列表中添加并勾选任务后，选中任务时中间区域
会显示该任务的设置与说明。

:::

::: details 任务的执行顺序是怎样的？

任务**按列表自上而下依次执行**，未勾选的任务会被跳过。可直接拖拽任务调整执行顺序。

:::

::: details 为什么不支持同时执行多个任务？

多个任务同时执行会导致操作相互干扰，因此 MAK 设计为顺序执行。

:::

::: details 什么是控制器？如何选择控制器？

控制器是 MaaFramework 中用于与游戏窗口交互的组件。MAK 当前提供 `ADB` 控制器。

请在配置页顶部的「控制器类型」中选择 `ADB 控制器`，再在「当前控制器」中选择需要连接的模拟器
或设备。

:::

::: details 如何判断任务是否正常运行？

可在右侧「实时视图」中查看设备画面，在「日志」中查看连接状态与运行信息。任务异常或失败时，
日志或界面通知中会给出相应提示。

:::
