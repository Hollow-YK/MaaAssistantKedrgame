# MXU 常见问题

本页收录 MXU 界面相关的常见问题。通用问题见[常见问题总览](./)。

## 界面与配置

::: details 什么是 MXU？

**MXU**（MaaFramework Next UI）是基于
[MaaFramework PI V2](https://github.com/MaaXYZ/MaaFramework/blob/main/docs/zh_cn/3.3-ProjectInterfaceV2%E5%8D%8F%E8%AE%AE.md)
协议的通用 GUI 客户端，为本项目提供开箱即用的图形界面。

:::

::: details 为什么推荐 MXU？

MXU 具有配置简单、交互方便、日志管理完善等优点，是目前主流 MaaFramework GUI 中与本项目最为
契合的界面。若 MXU 无法正常运行，可改用 [MFAA](../quickstart/mfaa)。

:::

::: details 什么是配置 / 标签页？

MXU 以标签页的形式展示 MaaFramework 配置，每个标签页相当于一套独立的配置，可为不同使用场景
分别创建配置。

:::

::: details 配置包括哪些范围？

- **任务独立**：任务列表、任务详细配置、任务启用状态与展开状态相互独立。
- **定时功能独立**：每个配置的定时执行设置互不影响。
- **连接设置独立**：控制器、连接窗口与实时截图显示状态相互独立。
- **全局设置共享**：「设置」中的内容由所有配置共享。

:::

::: details 关于预制配置

后续会将常用配置整合为若干预设，并在首次启动时自动应用。不需要时，关闭对应标签页即可删除。
若误删预设配置，可在新建配置时选择对应预设以恢复。

:::

::: details 关于定时执行配置

在配置右下角可设置定时执行，各配置的定时设置相互独立。

:::

## 任务与连接

::: details 什么是任务？

MAK 的各个自动化功能作为独立任务提供，可自由启用或禁用。每个任务对应游戏中的一项具体操作
或玩法。在任务列表中勾选需要执行的任务后，MAK 将按列表顺序依次执行。

:::

::: details 任务的执行顺序是怎样的？

任务**按列表自上而下依次执行**，未勾选的任务会被跳过。拖拽任务标题左侧的六个点可调整执行顺序。

:::

::: details 为什么不支持同时执行多个任务？

多个任务同时执行会导致操作相互干扰，因此 MAK 设计为顺序执行。

:::

::: details 什么是控制器？

控制器是 MaaFramework 中用于与游戏窗口交互的组件。MAK 提供一种控制器：`ADB`，可在右上角的
连接设置中选择。

:::

::: details 如何判断任务是否正常运行？

可在日志面板查看实时运行日志。任务异常或失败时，日志中会给出相应的错误提示。

:::
