## 通用问题

::: details MAK 支持哪些游戏版本？

目前主要支持《雪松》**官服**（从官网下载的版本）。B 服与 TapTap 服在通用资源的基础上加载对应
渠道资源，理论上也可使用。

:::

::: details 为什么任务不能同时执行？

MAK 通过图像识别与模拟操作实现自动化，多个任务同时执行会相互干扰。因此任务设计为**按列表自上而下
依次执行**。

:::

::: details 功能较少，后续是否会增加？

本项目目前处于早期开发阶段，由开发者利用业余时间维护。新功能将陆续添加，请关注
[GitHub Release](https://github.com/Hollow-YK/MaaAssistantKedrgame/releases) 页面。

:::

::: details 使用 MAK 是否会导致封号？

MAK 仅模拟手指点击屏幕，不会修改游戏数据，本质上与手动操作一致。

但根据游戏用户协议，使用第三方辅助工具存在一定风险。**请自行评估风险后使用**，本项目不对任何
后果负责。

:::

::: details macOS 是否可用？

MAK 目前仅支持 Windows 与 Android，暂不支持 macOS。
