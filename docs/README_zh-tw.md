## 功能一覽

- 登入遊戲
- 領取獎勵
- 自動戰鬥（僅限部分關卡）
- 玩家對戰（PVP 自動戰鬥，自動選擇等級最低的對手，支援多場次循環）
- 自動送禮/回禮
- 更多功能正在開發，敬請期待

## 常見問題

### 如何開始使用？

請前往 [Release](https://github.com/Hollow-YK/MaaAssistantKedrgame/releases) 選擇合適的版本下載。

也可以透過第三方分發平台 [MirrorChyan](https://mirrorchyan.com/zh/projects?rid=MAK) 下載（其 Windows 入口提供的是 MXU 版，MFAA 請仍從 Release 下載）。

更多內容見文件 [快速開始](https://hollow-yk.github.io/MaaAssistantKedrgame/guide/quickstart.html) 部分。

## 開發指南

請參考 [開發文件](https://hollow-yk.github.io/MaaAssistantKedrgame/dev/quick-start.html) ，並確保你提交的內容符合 [專案規範](https://hollow-yk.github.io/MaaAssistantKedrgame/dev/project-conventions/) 。除此之外，你可以參考 [MaaFramework 官方文件](https://maafw.com/docs/1.1-QuickStarted) 及其它優秀專案。

歡迎各路大佬貢獻程式碼，一起讓 MAK 變得更好！
