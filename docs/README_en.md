## Features

- Log in to the game
- Claim rewards
- Auto battle (limited stages only)
- PVP (auto battle, automatically picks the lowest-level opponent, supports multiple rounds in a loop)
- Auto send / return gifts
- More features are under development, stay tuned

## FAQ

### How do I get started?

Download a suitable version from [Release](https://github.com/Hollow-YK/MaaAssistantKedrgame/releases).

You can also download from the third-party distribution platform [MirrorChyan](https://mirrorchyan.com/en/projects?rid=MAK) (its Windows entry provides the MXU build; please still get MFAA from Release).

See the [Quick Start](https://hollow-yk.github.io/MaaAssistantKedrgame/en/guide/quickstart/) section of the documentation for more.
